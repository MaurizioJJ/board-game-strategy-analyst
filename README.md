# Board Game Strategy Analyst

Use Board Game Strategy Analyst in ChatGPT when you’re weighing an opening, choosing your next move, or trying to work out what an opponent can do. Tell it the game, edition, and player count, then describe the position or share a board photo.

The plugin starts with [Ludex](https://ludex.dev/) for rules and FAQs. It checks original rulings when a detail matters, links to the sources it uses, and explains the trade-offs behind its recommendation.

Published by Maurizio Masini. The plugin has no paid features or purchases.
