# Support

[Open a GitHub issue](https://github.com/MaurizioJJ/board-game-strategy-analyst/issues/new) for a wrong ruling, a broken source link, or a suggestion. Include the game, edition, the question you asked, and the rule or source you expected the plugin to use.

GitHub issues are public. Keep personal information, private chats, and photos with identifiable people out of your report. You can edit your own report on GitHub or ask the maintainer to remove an attachment or close the issue.

For ChatGPT account or billing help, visit the [OpenAI Help Center](https://help.openai.com/).
