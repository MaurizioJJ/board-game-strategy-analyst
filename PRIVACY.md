# Privacy policy

This policy covers Board Game Strategy Analyst, published by Maurizio Masini, and its public support repository.

## Using the plugin

The plugin consists of instructions that run in ChatGPT. It has no publisher-operated account, payment system, or server. Prompts and uploaded board photos are handled by ChatGPT under [OpenAI’s privacy policy](https://openai.com/policies/privacy-policy/). The plugin does not send your prompts or uploads to a publisher-operated service.

The instructions direct ChatGPT to consult public sources such as Ludex. If you visit a linked source, that website handles your visit under its own practices. Describe the game state using game details and crop personal information out of board photos before uploading them.

## Support on GitHub

If you open a support issue, the maintainer uses your GitHub username, report, and any attachments you choose to share to investigate and respond. Public issues remain visible in the issue history unless edited or removed. GitHub handles account and website data under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

To ask about this policy or request that the maintainer remove personal information from an issue, use the [support page](SUPPORT.md). Refer to the issue number without repeating the personal information.
